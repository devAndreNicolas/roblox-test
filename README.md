Generated by [Rojo](https://github.com/rojo-rbx/rojo) 7.7.1.

## Getting Started
To build the place from scratch, use:

```bash
rojo build default.project.json -o "roblox-test.rbxlx"
```

Next, open `roblox-test.rbxlx` in Roblox Studio and start the Rojo server:

```bash
rojo serve
```

For more help, check out [the Rojo documentation](https://rojo.space/docs).

## Projetos de publicação e de teste

`default.project.json` monta somente `src/` e é o projeto para publicar. Para testar no Studio, encerre o servidor Rojo anterior, inicie `rojo serve studio.project.json` e conecte o plugin Rojo a esse servidor. O projeto de teste acrescenta `tests/studio/ProfileStoreAdapter.luau` e `tests/studio/StudioPassPurchase.server.luau`; ambos ficam fora da versão de publicação. O adaptador de produção bloqueia acesso a perfis reais quando executado no Studio sem o projeto de teste. Reinicie o playtest após trocar de projeto.
