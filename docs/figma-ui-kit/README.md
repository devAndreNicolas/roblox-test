# Figma component workflow

1. Paste [SKILL.md](SKILL.md) into Figma as the persistent project brief.
2. Use [01-buttons.md](01-buttons.md) first. It maps every current interactive control and asks for **button components only**.
3. Use the family prompts in [02-elements.md](02-elements.md), one numbered family at a time. Do not ask Figma to assemble a full screen yet.
4. Check each result against [INVENTORY.md](INVENTORY.md). Save approved component variants and isolated exports with the documented names.
5. Assemble screens from approved components in Figma. Then transfer layout and appearance into the Studio templates described in [assets/ui/README.md](../../assets/ui/README.md).

The Figma files are design references. Roblox Studio templates own the in-game appearance. Luau owns dynamic text, state, purchases, currencies and rewards. Existing `assets/bingo/` card frames and offer icons are references for redesign, not a requirement to keep the old artwork.
